# 架构与 ADR

## 1. 路径是信息结构

KB 是独立命名空间，`entries(kb,path)` 唯一。文件夹是独立条目，根目录隐式存在；文件夹页根据直接子路径生成列表，左侧递归形成文件树。文件夹不承载正文，因此不存在父文档包含子文档的关系。

资源都拥有稳定 UUID。移动/重命名保持 UUID，对完整子树执行事务更新。所有 SQL 使用绑定参数；子树匹配使用字面前缀，不使用会把 `%`、`_` 解释成通配符的 LIKE。

## 2. SQLite 元数据 + 不可变文件

```
data/
  folio.sqlite       # KB、路径、版本、批注、会话
  folio.sqlite-wal    # SQLite 运行期文件
  folio.sqlite-shm
  blobs/<uuid>       # 原始字节，替换时写新的 UUID
```

上传流以分块方式写入临时 blob，同时检查总大小。写盘、flush/sync 后，事务获得 SQLite 写锁，检查父目录、路径、版本、文件 ID；原子 rename 后更新元数据并提交。并发上传只能有一个匹配同一版本，其他返回 409。

旧 blob 不立即删除，使在线备份和导出可使用一致的元数据快照。显式停机 GC 负责回收未引用文件。进程意外退出可能留下未引用 blob 或临时文件，GC 会处理；不会把未写完的 blob 挂到目录中。

数据库 WAL 模式，最多 8 个连接，10 秒 busy timeout。HTTP 使用异步 IO；导出 ZIP 的文件打包放在阻塞工作线程，下载以文件流返回。压缩交给 Caddy，避免压缩影响 Range 语义。

## 3. Workbench

桌面（≥1100 px）保留活动栏、资源面板、主文档和检查面板；平板（700–1099 px）自动压缩资源面板，检查面板改成抽屉；手机（<700 px）通过底部导航与抽屉操作。拖动面板标题可停靠左右或底部，分隔条支持鼠标/触控笔和键盘调整，面板可隐藏；设置里可恢复默认。

阅读区沿用 EA.KB.IO 的暖纸色、衬线标题、棕色强调。依赖通过 npm lockfile 固定；字体随构建提供，无 CDN 请求。

## 4. 渲染

- MD：参考项目的 marked/KaTeX/Shiki 管线，DOMPurify 清理 HTML，再用 strict 模式 Mermaid 水合图表。纯 textarea 编辑，约 100 ms 延迟更新预览。
- PDF：懒加载 PDF.js 与 worker。在线优先 Range 请求首屏内容，后台补齐原文件缓存。已缓存版本直接从缓存字节渲染。一次只渲染当前页，Canvas 按设备像素比输出。
- PDF comments：`entry + version + page + normalized(x,y)`。随页面缩放重定位；文件替换后旧版本批注标识为旧版本，重命名会同步当前批注版本。批注以 JSON 与 ZIP 一起导出，不修改 PDF 原文件。
- DOCX：docx-preview → DOMPurify → 无脚本权限的 sandbox iframe。基础分页、表格、页眉页脚和内嵌图片。复杂 Office 排版以导出原文件为准。
- HTML：iframe `sandbox=allow-scripts`，无 `allow-same-origin`。CSP 仅允许内联样式、脚本、data/blob 图片及 data 字体，禁止网络、表单提交与 base URL；适合真正自包含的交互 HTML。

## 5. 离线管线

1. 生产构建 Service Worker 预缓存应用外壳、CSS、基础字体和图标，约 0.86 MiB。
2. 目录和 PDF 批注采用 network-first，仅在网络异常时退回缓存；不把 401/403/500 作为可缓存内容。
3. 文档以 `entry-id + version` URL cache-first，文件替换天然产生新的键。只存完整 200 响应，Range 206 不入文档缓存。
4. 阅读器 JS、PDF 字体/字符映射、数学字体使用按访问缓存。整库缓存会先取完整阅读器清单（4 路并发），再按顺序取原文件及批注。
5. 文档缓存约 200 MiB、按插入顺序淘汰；应用与阅读器缓存分开。浏览器可拒绝持久化或清理缓存，UI 不将缓存当作唯一存储。
6. MD 输入立即写入 IndexedDB，手动保存或「同步草稿」才提交远端。离线保存不伪装成服务器成功。冲突时保留草稿；所有草稿可导出 JSON，包括已移动/删除文件的草稿。
7. 退出登录清除本机私有文档缓存和草稿，应用资源继续可用。浏览器更新采用提示式 activation，草稿可跨刷新恢复。

## 6. 协同和身份

个人用户模型：同一个空间密码在多设备登录，每台设备获得随机 HttpOnly cookie；服务器只存 session token 的 SHA-256 摘要。会话 30 天有效，SameSite=Strict；线上 Secure cookie。登录失败限速为单进程全局每分钟最多 20 次尝试。密码来自环境，不进入前端构建。

修改操作要求自定义请求头，无跨域 CORS。更新文件必须同时发送 `If-Match: "version"` 和 `X-Folio-Entry: uuid`，防止同名替换后旧稿误写。移动与删除以 UUID 路由和版本检查执行。没有覆盖冲突的隐式重试。

目录和当前 PDF 批注每 15 秒刷新，切回窗口也刷新。原型不提供多人身份、邀请、细粒度 ACL 或操作转换。

## 7. 运维取舍

单实例、小型个人库；上传和 ZIP 导出需要数据盘足够可用空间。未来可增加对象存储适配、分页目录索引、回收站/版本历史、批注导入与全文检索。当前仍以路径和原文件导出为可迁移边界。
